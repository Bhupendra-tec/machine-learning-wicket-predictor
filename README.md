# 🏏 NPL Cricket Intelligence
**Disclaimer:** This project is developed solely for educational and academic purposes. The machine learning predictions are experimental estimates and do not guarantee 100% accuracy. Actual cricket match outcomes may differ from the predictions generated by this system.

### Experimental Machine Learning Prediction System

NPL Cricket Intelligence is a machine learning-based cricket
analytics application designed to explore ball-by-ball data
from the Nepal Premier League (NPL) 2024 only.This is only for 
project purpose and doesnot necessarily predict the 100% accurate result.

The project analyzes historical cricket deliveries and estimates
the probability of a wicket occurring on the next delivery.

It combines data analysis, machine learning, and an interactive
Streamlit dashboard.

---

## Project Overview

The main objective of this project is to explore how machine
learning algorithms can analyze cricket match situations
and estimate wicket probabilities.

Users can enter match conditions, select batting and bowling
players, and receive an experimental wicket probability estimate.

### Main Features

•⁠  ⁠NPL ball-by-ball data analysis
•⁠  ⁠Cricket match statistics
•⁠  ⁠Wicket probability prediction
•⁠  ⁠Interactive Streamlit dashboard
•⁠  ⁠Batting and bowling team selection
•⁠  ⁠Player and bowling-style selection
•⁠  ⁠Match situation inputs
•⁠  ⁠Prediction history
•⁠  ⁠Model performance comparison
•⁠  ⁠Data visualization

---

## 🧠 Machine Learning Algorithms

Five classification algorithms were implemented and evaluated.

1.⁠ ⁠Logistic Regression
2.⁠ ⁠Support Vector Machine (SVM)
3.⁠ ⁠Decision Tree
4.⁠ ⁠K-Nearest Neighbors (KNN)
5.⁠ ⁠Random Forest

The Decision Tree model achieved the best PR-AUC among
the five evaluated models in the current experiment.

| SVM | 57.16% | 6.04% | 39.81% | 10.49% | 49.67% | 7.06% |

Note: KNN achieved 93.70% accuracy, but this result is influenced by the class imbalance in our dataset. The model predicted every delivery as No Wicket and failed to identify actual wickets. Therefore, accuracy alone does not represent its predictive performance. We evaluated additional metrics, including Precision, Recall, F1-score, and PR-AUC, to make a more meaningful model comparison.
